# Блогеры: рабочий стол

Тестовое для ZAUM. Взял таблицу с блогерами и сделал из неё небольшой сервис, в котором удобно смотреть, что происходит с размещениями.

Демо: https://vegas2101.github.io/zaum-bloggers-demo/

## Что получилось

Сверху четыре цифры: сколько ушло на платные размещения, сколько стоит товар по бартеру, средний CPM и лучший CPM. Дальше блок «Требует внимания»: там то, до чего у менеджера руки доходят в первую очередь. Это размещения с прошедшей датой и старым статусом, выходы в ближайшие два дня и опубликованные, по которым ещё нет результатов.

Ниже список блогеров. Можно фильтровать по статусу, площадке и бюджету, искать по имени или артикулу и сортировать. На телефоне таблица превращается в карточки, по клику открываются все данные и ссылка на рекламу. Есть тёмная тема.

## Решения

- Без фреймворков и сборки, один html-файл. Данных 24 строки, больше не нужно, зато открывается где угодно.
- Затраты: у платных размещений стоимость размещения, у бартера себестоимость товара. CPM = затраты / охват сторис * 1000, без охвата CPM не считается.
- Сводка сверху всегда по всем размещениям, фильтры и поиск её не меняют.
- Данные вшиты в страницу, это копия демо-таблицы. «Сегодня» зафиксировано на дату выгрузки (4 ноября 2026), иначе статичные данные со временем покраснели бы целиком.

## Структура

- `index.html` — готовый сервис
- `src/template.html` — исходник интерфейса
- `data.json` — данные из таблицы
- `build.py` — собирает `index.html` (`python3 build.py`)
